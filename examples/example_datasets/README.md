# Example Datasets

This directory contains example protein engineering datasets for use with **protpy**. Each dataset is a comma-separated TXT file with a header row; columns common to all files are described below. A pre-computed descriptor matrix for the thermostability dataset is also provided.

---

## Common Columns

| Column | Description |
|--------|-------------|
| `name` | Unique variant identifier (string, e.g. `00000000` or `W122A`) |
| `sequence` | Full amino acid sequence in single-letter code |
| `is_train` | Boolean flag indicating whether the row belongs to the training split |
| `m` | Number of mutations relative to the parent/wild-type sequence |

Each dataset adds one task-specific label column described in its section below.

---

## Dataset Files

### `thermostability.txt`

Protein thermostability dataset. Sequences are cytochrome P450 variants engineered for altered thermal stability.

| Column | Type | Description |
|--------|------|-------------|
| `T50` | float | Temperature (°C) at which 50% of enzyme activity is lost after a 10-minute incubation |

- **Sequences:** 260
- **Sequence length:** ~430–480 residues (some variants contain gap characters from MSA alignment)
- **Task:** regression — predict `T50` from sequence

```python
import protpy

data = protpy.read_sequences_from_file(
    "examples/example_datasets/thermostability.txt",
    seq_col="sequence",
    id_col="name",
)
# Returns a DataFrame with columns ['name', 'sequence'] (260 rows)
```

- **Task:** regression — predict peak absorption wavelength from sequence


### `enantioselectivity.txt`

| Column | Type | Description |
|--------|------|-------------|
| `e-value` | float | Enantiomeric excess (E-value); higher values indicate greater selectivity for one enantiomer |

- **Sequences:** 151
- **Task:** regression — predict enantioselectivity from sequence


## Pre-computed Descriptor File

### `descriptors_thermostability.csv`

Pre-computed descriptor matrix for the thermostability dataset, generated by running `encode_dataset` on all 260 sequences in `thermostability.txt`. Gap characters (`-`) present in MSA-aligned sequences are stripped before encoding.

| Property | Value |
|----------|-------|
| **Shape** | 260 rows × 10,758 columns |
| **First column** | `name` — sequence identifier matching `thermostability.txt` |
| **Remaining columns** | All protpy descriptor features (10,757 features with default parameters) |
| **Source file** | `thermostability.txt` |

The file can be loaded directly as a DataFrame and joined back to the original labels:

```python
import pandas as pd

descriptors = pd.read_csv("examples/example_datasets/descriptors_thermostability.csv")
# Shape: (260, 10758) — first column is 'name', remaining are descriptor features

labels = pd.read_csv(
    "examples/example_datasets/thermostability.txt",
    usecols=["name", "T50", "is_train"],
)
df = descriptors.merge(labels, on="name")
# Ready to split on is_train and train a regression model
```

To regenerate this file from scratch:

```python
import protpy

data = protpy.read_sequences_from_file(
    "examples/example_datasets/thermostability.txt",
    seq_col="sequence",
    id_col="name",
)
descriptors = protpy.encode_dataset(
    data,
    seq_col="sequence",
    output_file="examples/example_datasets/descriptors_thermostability.csv",
    strip_gaps=True,
)
```
